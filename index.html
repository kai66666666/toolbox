个人 HTML 小工具

一个可以直接部署到 GitHub Pages 的静态工具集合，所有工具都在浏览器本地运行。

C 打开工具

颜色预览

输入或选择颜色值，快速查看颜色效果，适合调试页面、组件和视觉稿中的色值。
P 打开工具

强类型密码生成器

一次生成 10 个强密码，支持长度、大小写、数字和特殊符号配置，并可一键复制。
T 打开工具

时间戳转换工具

秒级、毫秒级 Unix 时间戳与本地时间、北京时间、ISO 字符串之间双向转换。
K 打开工具

公私钥生成工具

生成或输入一组 RSA 公钥和私钥，支持加解密、SHA256withRSA 签名验签、导出和复制。
H 打开工具

编码解码与摘要工具

常见 Base64、URL、HTML 实体、Hex 编码解码，并实时生成 SHA-256 摘要。
建议仓库开启 GitHub Pages 后，从根目录直接发布。
